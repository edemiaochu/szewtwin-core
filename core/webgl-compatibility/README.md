## Description

The __@szewtwin/webgl-compatibility__ package provides APIs for determining the level of compatibility of a browser+device with the szewTwin.js rendering system.

This package is used by the [szewTwin.js Compatibility Checker website](https://szewtwinjscompatibility.szewec.com/) to evaluate whether
a user's browser and hardware meet the requirements for running szewTwin.js applications.
