# @szewtwin/core-quantity

The __@szewtwin/core-quantity__ package contains classes for quantity formatting and parsing. For detailed API documentation, see our [szewTwin.js reference documentation](https://www.szewtwinjs.org/reference/core-quantity/quantity/).

Also check the [szewTwin.js learning documentation](https://www.szewtwinjs.org/learning/quantity) explaining quantity formatting and its basic concepts.

## Contributing

When adding new APIs or updating documentation for this package, review if [QuantityFormatting.md](https://github.com/szewTwin/szewtwinjs-core/blob/master/docs/learning/frontend/QuantityFormatting.md) or the [core-quantity learning page](https://github.com/szewTwin/szewtwinjs-core/blob/master/docs/learning/quantity/index.md) needs to be updated as well. When adding or editing code examples, it's encouraged to keep the examples consistent between this file and the linked file above.

See the [Contributing.md](https://github.com/szewTwin/szewtwinjs-core/blob/master/CONTRIBUTING.md) for more details.
